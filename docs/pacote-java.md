# Opções do pacote Java

O instalador Java oficial do PEC aceita os seguintes argumentos:

```text
Usage: <main class> [[-url=<url>] [-username=<username>]
                    [-password=<password>]] [[-restore=<dumpFilePath>]]
                    [[-backup]] [-console] [-continue] [-help] [-treinamento]
```

| Parâmetro | Descrição |
|---|---|
| `-console` | Inicializa o assistente em linha de comando. |
| `-treinamento` | Cria uma instalação de treinamento. Sem ele, a instalação é de produção. |
| `-help` | Exibe a ajuda do instalador. |
| `-continue` | Executa as tarefas sem pedir confirmação. |
| `-url=<url>` | Define a URL de conexão com o banco. |
| `-username=<username>` | Define o usuário do banco. |
| `-password=<password>` | Define a senha do banco. |
| `-restore=<dumpFilePath>` | Restaura o arquivo de backup informado. |
| `-backup` | Cria um backup antes da atualização. |

Consulte também o [portal oficial do e-SUS APS](https://sisaps.saude.gov.br/esus/) e a [página de suporte](https://esusaps.freshdesk.com/support/login).
