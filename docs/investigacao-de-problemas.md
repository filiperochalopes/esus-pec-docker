# Investigação de problemas

Este repositório também pode ser usado para reproduzir uma instalação e investigar problemas de aplicação ou dados em um ambiente isolado.

> [!WARNING]
> Dados de saúde são sensíveis. Nunca envie dados reais, backups identificáveis, credenciais ou endereços de produção a serviços externos. Prefira modelos locais e dados anonimizados ou sintéticos.

Exemplo com Ollama:

```sh
ollama launch opencode --model qwen3.5:9b-mlx
```

Ou execute o OpenCode com uma configuração local, como LM Studio:

```sh
opencode
```

Para inspecionar o código do PEC, veja [Geração do codebase](codebase.md).
